## Description du projet
Ce TP a pour objectif de réaliser une analyse et une détection des URL malveillantes (phishing) à l'aide de techniques de Machine Learning et d'Intelligence Artificielle explicable.

## Objectifs
- Explorer et analyser le dataset PhiUSIIL.
- Réaliser une analyse exploratoire des données (EDA).
- Préparer les données pour l'entraînement.
- Entraîner plusieurs modèles de régression logistique.
- Évaluer les performances des modèles.
- Utiliser SHAP pour interpréter les prédictions.

## Technologies et bibliothèques
- Python
- Google Colab
- Pandas et NumPy
- Matplotlib et Seaborn
- Scikit-learn
- SHAP

## Dataset
Le projet utilise le dataset **PhiUSIIL Phishing URL Dataset** pour distinguer les URL légitimes des URL de phishing.

## Structure du projet
- `M115_Lab1.ipynb` : Notebook contenant le code, les analyses, les visualisations et les résultats.

## Exécution
1. Ouvrir le notebook avec Google Colab.
2. Charger le dataset PhiUSIIL.
3. Installer les bibliothèques nécessaires.
4. Exécuter les cellules dans l'ordre.

## Résultat attendu
Développer un modèle capable de détecter les URL de phishing et comprendre les facteurs qui influencent ses prédictions grâce à SHAP.
